@001
Q: Qu'est-ce qu'une installation Server Core de Windows Server ?
C: Une installation sans bureau graphique, administrée en ligne de commande ou à distance
W: Une version gratuite limitée à un seul rôle, réservée aux tests
W: L'édition qui contient tous les rôles, au contraire de l'édition Standard dont plusieurs rôles sont retirés
W: Le noyau seul, sans réseau ni pilotes, destiné aux conteneurs
E: Server Core réduit la surface d'attaque, le nombre de mises à jour et la mémoire consommée. On l'administre avec sconfig, PowerShell, Windows Admin Center ou les consoles RSAT d'un poste. Depuis Windows Server 2016, on ne passe plus de Core à l'expérience bureau sans réinstaller.

@002
Q: Quelle différence de licence sépare principalement Windows Server Standard et Datacenter ?
C: Datacenter couvre un nombre illimité de VM Windows Server sur l'hôte, Standard deux
W: Standard ne peut pas devenir contrôleur de domaine
W: Datacenter est réservé aux serveurs de plus de 64 cœurs
W: Standard n'accepte pas les scripts PowerShell signés par un tiers ni les modules de la galerie
E: Les deux éditions se licencient par cœur physique, 16 cœurs au minimum par serveur. Standard donne droit à deux machines virtuelles Windows Server par licence complète, Datacenter à un nombre illimité, avec en plus Storage Spaces Direct ou les VM blindées. Au-delà d'une dizaine de VM par hôte, Datacenter devient généralement rentable.

@003
Q: Dans le Gestionnaire de serveur, quelle est la différence entre un rôle et une fonctionnalité ?
C: Un rôle rend un service au réseau (DNS, DHCP, AD DS) ; une fonctionnalité outille le serveur lui-même
W: Un rôle est payant, une fonctionnalité gratuite
W: Une fonctionnalité ne s'installe qu'en PowerShell
W: Un rôle s'applique à un utilisateur, une fonctionnalité à un ordinateur du domaine

@008
Q: Quel est le rôle d'un contrôleur de domaine Active Directory ?
C: Héberger une copie de l'annuaire et authentifier les comptes du domaine
W: Distribuer les adresses IP aux postes
W: Stocker les profils itinérants des utilisateurs
W: Servir de passerelle Internet aux postes du domaine et filtrer les flux entrants et sortants
E: Chaque contrôleur de domaine porte une copie de la base NTDS.dit, répliquée avec les autres. On en prévoit au moins deux par domaine : si l'unique contrôleur tombe, plus personne ne peut ouvrir de session réseau ni accéder aux ressources protégées.

@009
Q: Associer chaque objet Active Directory à sa définition.
P: Forêt => Limite de sécurité, ensemble de domaines partageant un schéma
P: Domaine => Limite d'administration et de réplication des comptes
P: Unité d'organisation => Conteneur pour déléguer et appliquer des GPO
P: Site => Groupe de sous-réseaux bien reliés, pour la réplication et l'authentification
P: Groupe => Ensemble de comptes auxquels on donne des droits
E: La forêt est la vraie frontière de sécurité, pas le domaine : un administrateur du domaine racine peut prendre la main sur toute la forêt. Les OU suivent l'organisation de l'administration (qui gère quoi), les sites suivent le réseau physique.

@010
Q: Pourquoi les postes d'un domaine doivent-ils utiliser les serveurs DNS du domaine plutôt que celui de la box ou de Google ?
C: Ils trouvent les contrôleurs de domaine grâce aux enregistrements SRV de la zone AD
W: Le DNS public ignore les noms courts, ce qui empêche toute ouverture de session sur un poste Windows
W: Le DNS du domaine est plus rapide pour Internet
W: Pour chiffrer les requêtes
E: Un poste configuré avec 8.8.8.8 ne trouve pas _ldap._tcp.dc._msdcs.<domaine> : jonction impossible, ouvertures de session lentes, GPO non appliquées. Les DNS du domaine résolvent Internet eux-mêmes ou par des redirecteurs.

@011
Q: Remettre dans l'ordre l'échange entre un poste et un serveur DHCP.
O: DHCPDISCOVER : le poste cherche un serveur par diffusion
O: DHCPOFFER : le serveur propose une adresse
O: DHCPREQUEST : le poste demande l'adresse proposée
O: DHCPACK : le serveur confirme et fixe la durée du bail
E: On retient DORA. Le poste renouvelle son bail à 50 % de sa durée, directement auprès du serveur. Si le serveur est sur un autre sous-réseau, le routeur doit relayer la diffusion (ip helper-address) vers lui.

@012
Q: Un poste affiche l'adresse 169.254.12.40. Qu'en conclure ?
C: Il n'a obtenu aucune réponse d'un serveur DHCP
W: Il a reçu une adresse publique
W: Son adresse est fixée à la main par un administrateur
W: Il est connecté au VPN de l'entreprise, qui lui attribue une adresse de cette plage réservée
E: La plage 169.254.0.0/16 (APIPA) est auto-attribuée quand le DHCP ne répond pas. Pistes : câble ou VLAN, relais DHCP absent, étendue pleine, service arrêté ou serveur non autorisé dans AD. ipconfig /renew relance la demande.

@013
Q: Un dossier partagé donne « Contrôle total » à Tout le monde au niveau du partage et « Lecture » à un utilisateur en NTFS. Que peut faire cet utilisateur à travers le réseau ?

@014
Q: Un utilisateur est membre de deux groupes : l'un a « Modification » sur un dossier, l'autre un refus explicite d'écriture. Quel est le résultat ?

@015
Q: Qu'est-ce qu'une stratégie de groupe (GPO) ?
C: Un ensemble de paramètres appliqué aux utilisateurs ou ordinateurs d'un site, domaine ou OU
W: Un groupe de sécurité qui contient des stratégies
W: Un script lancé une fois à l'installation de Windows
W: La liste des mots de passe autorisés dans le domaine, stockée en clair sur chaque poste client
E: Une GPO a une partie Ordinateur, appliquée au démarrage puis toutes les 90 minutes environ, et une partie Utilisateur, appliquée à l'ouverture de session. Elle n'agit qu'une fois liée à un site, un domaine ou une OU ; les conteneurs par défaut Users et Computers ne peuvent pas recevoir de GPO.

@017
Q: Sur quel port TCP écoute par défaut le Bureau à distance (RDP) ?
N: 3389
E: RDP utilise TCP 3389, et UDP 3389 pour améliorer la fluidité. On ne l'expose jamais directement sur Internet : passerelle RD Gateway, VPN ou bastion avec authentification multifacteur. Les attaques par force brute sur ce port sont permanentes.

@019
Q: Que renvoie cette commande ?
C: Les services à démarrage automatique qui sont arrêtés
W: Tous les services arrêtés, quel que soit leur type de démarrage
W: Les services automatiques, qu'ils tournent ou non
W: Une erreur, car Where-Object n'accepte qu'une seule condition par bloc de script

```powershell
Get-Service | Where-Object { $_.StartType -eq 'Automatic' -and $_.Status -eq 'Stopped' }
```

@026

@027
Q: Sur quel serveur d'une forêt lance-t-on cette commande qui fixe une source de temps externe ?
C: L'émulateur PDC du domaine racine de la forêt
W: Chaque poste client, pour qu'il interroge directement pool.ntp.org sans passer par les contrôleurs
W: Le maître de schéma
W: Tous les contrôleurs de domaine, chacun avec sa propre source NTP
E: Les postes se calent sur leur contrôleur, les contrôleurs sur le PDC de leur domaine, et le PDC racine sur la source externe : c'est la hiérarchie que Kerberos attend. Sur une VM, on désactive pour ce contrôleur la synchronisation de l'heure par l'hyperviseur, sinon elle reprend la main.
```powershell
w32tm /config /manualpeerlist:"pool.ntp.org" /syncfromflags:manual /reliable:yes /update
```

@029

@030

@036
Q: Quelle méthode recommande Microsoft pour donner l'accès à un dossier dans un domaine ?

@037
Q: Associer chaque étendue de groupe à ses règles.

@041
Q: Qu'est-ce que le partage SYSVOL d'un contrôleur de domaine ?

@042
Q: Que produit ce pipeline ?
C: Les cinq processus qui consomment le plus de mémoire, avec leur nom et leur mémoire en Mo
W: Les cinq premiers processus par ordre alphabétique
W: Les cinq processus les plus anciens
W: Une erreur, car l'expression calculée est mal formée
E: Sort-Object -Descending trie du plus grand au plus petit, Select-Object -First 5 garde le début. La table @{Name=…; Expression=…} crée une propriété calculée : WorkingSet est en octets, la division par 1MB donne des mégaoctets.
```powershell
Get-Process | Sort-Object WorkingSet -Descending |
    Select-Object -First 5 Name, @{Name='Mo'; Expression={ [math]::Round($_.WorkingSet / 1MB) }}
```

@043

W: Where-Object ne sait pas comparer des chaînes
W: -Filter * est interdit hors des contrôleurs de domaine
W: La première cherche dans l'OU courante seulement, ce qui réduit le risque de modifier un autre service
E: Règle « filtrer à gauche » : sur un annuaire de 20 000 comptes, la seconde forme rapatrie tout puis trie sur le poste. Même logique pour Get-WinEvent -FilterHashtable plutôt qu'un Where-Object après coup.
```powershell
Get-ADUser -Filter "Department -eq 'Compta'" -Properties Department
Get-ADUser -Filter * -Properties Department | Where-Object Department -eq 'Compta'
```

@046
Q: Que fait cette commande ?
C: Elle exécute le bloc en parallèle sur les trois serveurs et renvoie les résultats, marqués du nom de chaque machine

@047
Q: Dans cette session ouverte sur SRV01, la seconde commande renvoie « Accès refusé ». Quelle est la cause habituelle ?
C: Le double saut : SRV01 ne peut pas réutiliser vos identifiants pour aller sur SRV02
W: Le partage n'existe pas
W: PowerShell distant ne gère pas les chemins UNC
W: Le pare-feu de votre poste bloque les connexions SMB sortantes vers SRV02 depuis la session
E: Avec Kerberos, vos identifiants ne sont pas délégués au premier serveur. Solutions : délégation contrainte basée sur les ressources (RBCD) de SRV01 vers SRV02, ou -Credential passé explicitement. CredSSP résout aussi le problème mais laisse le mot de passe sur SRV01 : à éviter.
```powershell
Enter-PSSession -ComputerName SRV01
Get-ChildItem \\SRV02\partage
```

@048
Q: Pourquoi le bloc catch de ce script n'est-il jamais exécuté quand le fichier n'existe pas ?
C: Get-Item émet une erreur non bloquante ; il faut -ErrorAction Stop pour l'intercepter
W: catch n'intercepte que les exceptions levées par les méthodes .NET, jamais celles des cmdlets
W: Write-Warning masque l'erreur
W: Le chemin doit être entre guillemets doubles pour que l'erreur remonte au bloc catch
E: La plupart des cmdlets continuent après une erreur non bloquante, sans passer par catch. -ErrorAction Stop sur la commande, ou $ErrorActionPreference = 'Stop' en tête de script, change ce comportement. $_.Exception.Message donne le texte de l'erreur dans le catch.
```powershell
try {
    Get-Item 'D:\Export\rapport.csv'
}
catch {
    Write-Warning "Fichier absent"
}
```

@049
Q: Compléter ce script qui exporte les comptes désactivés dans un fichier lisible par Excel.
A: Export-Csv
E: -NoTypeInformation retire la ligne #TYPE ajoutée par Windows PowerShell 5.1 (PowerShell 7 ne l'écrit plus). Avec un Excel français, -Delimiter ';' évite que tout tienne dans une seule colonne, et -Encoding UTF8 garde les accents.
```powershell
Search-ADAccount -AccountDisabled -UsersOnly |
    Select-Object Name, SamAccountName, DistinguishedName |
    ____ -Path C:\Export\desactives.csv -NoTypeInformation -Delimiter ';' -Encoding UTF8
```
