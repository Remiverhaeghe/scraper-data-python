W: Le thread principal relit la mémoire toutes les secondes

E: Le modèle mémoire de Java garantit que tout ce qu'un thread a écrit est visible par un autre thread qui a réussi un join sur lui : c'est une relation « arrive-avant ». @088
Q: Pourquoi ce singleton à double vérification exige-t-il volatile sur instance ?
C: Un objet à moitié construit
W: Sans volatile, deux instances sont créées à chaque appel
W: volatile rend le constructeur plus rapide
W: volatile remplace le bloc synchronized
E: L'écriture de la référence peut être réordonnée avant la fin du constructeur : un autre thread, qui ne passe pas par synchronized au premier test, peut alors voir un objet partiellement initialisé. volatile interdit ce réordonnancement. Le problème n'est pas une double création systématique. volatile n'accélère rien et ne remplace pas le verrou. On préfère souvent un holder statique ou une énumération.
```
private static volatile Service instance;

static Service getInstance() {
    if (instance == null) {
        synchronized (Service.class) {
            if (instance == null) {
                instance = new Service();
            }
        }
    }
    return instance;
}
```

Les records n'interdisent pas default.

```
double aire(Forme forme) {
    return switch (forme) {
        case Carre c -> c.cote() * c.cote();
        case Cercle c -> Math.PI * c.rayon() * c.rayon();
    };
}
```

@100
Q: Que se passe-t-il à la fin de ce bloc try ?
C: Les ressources sont fermées en ordre inverse, b puis a
W: Les ressources sont fermées dans l'ordre, a puis b
W: Seule la dernière ressource ouverte est fermée
W: Aucune ressource n'est fermée sans finally
E: try-with-resources ferme les ressources dans l'ordre inverse de leur ouverture : b d'abord, puis a, car b dépend souvent de a. Si une fermeture lève une exception pendant qu'une autre est déjà en cours, elle est ajoutée comme exception supprimée. Toutes les ressources sont fermées, sans finally.
```
try (Ressource a = ouvrir("a");
     Ressource b = ouvrir("b")) {
    traiter(a, b);
}
```
