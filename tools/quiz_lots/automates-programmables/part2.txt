E: L'IHM, la supervision, d'autres automates ou un serveur utilisent l'adresse actuelle : il faut les recenser, vérifier que la nouvelle adresse est libre et planifier la mise à jour de tous ces clients. Les clients ne découvrent pas seuls une nouvelle adresse fixe. Une adresse prise au hasard peut entrer en conflit ou sortir du plan d'adressage. Désactiver le pare-feu ajoute un risque sans aider au changement.

VAR

@060
Q: Pourquoi `DefautMemorise` reste-t-il TRUE après la disparition de `DefautInstantane` ?
C: Il attend que l'opérateur acquitte le défaut
W: Le défaut instantané est relu au cycle suivant
W: Le programme ne peut l'effacer qu'en mode STOP
W: Une variable BOOL ne peut pas revenir à FALSE
E: Le défaut reste mémorisé tant qu'il n'est pas acquitté : l'opérateur prend connaissance de l'événement même s'il a été bref. La branche ELSIF n'est évaluée que si le défaut a disparu, ce qui empêche d'acquitter un défaut toujours présent. Relire l'entrée au cycle suivant ne remet pas la mémoire à FALSE. Le programme l'efface en marche, sans passage en STOP, et une variable BOOL change librement de valeur.
```
VAR
    DefautInstantane, Acquittement : BOOL;
    DefautMemorise : BOOL;
END_VAR

IF DefautInstantane THEN
    DefautMemorise := TRUE;
ELSIF Acquittement THEN
    DefautMemorise := FALSE;
END_IF;
```

@062
Q: Que signifie `RETAIN` dans cette déclaration ?
C: Sa valeur est conservée après une coupure secteur
W: La variable est remise à zéro à chaque cycle automate
W: La variable ne peut plus être écrite par le programme
W: La variable est liée à une entrée physique de la CPU
E: Une variable rémanente garde sa valeur après une coupure ou un redémarrage, selon la zone de rémanence de la CPU : ici, le compteur de pièces n'est pas perdu. Aucune variable n'est remise à zéro à chaque cycle sans instruction. RETAIN n'interdit pas l'écriture : le programme l'incrémente justement. Le lien avec une entrée physique passe par l'adressage, pas par RETAIN.
```
VAR RETAIN
    CompteurPieces : DINT := 0;
END_VAR

CompteurPieces := CompteurPieces + 1;
```

@063

@064

W: Le temps de cycle de la tâche qui lit cette valeur

@065
Q: À quoi sert le test qui précède l'accès à `Valeurs[Index]` ?
C: Empêcher un accès hors des limites du tableau
W: Accélérer la lecture des valeurs du tableau
W: Initialiser toutes les valeurs du tableau à zéro
W: Convertir l'indice INT en indice réel autorisé
E: Valeurs est déclaré de 0 à 9 : un Index négatif ou supérieur à 9 lirait en dehors du tableau, ce qui provoque une erreur d'exécution ou une valeur aberrante selon la plateforme. Le test ajoute une petite charge, il n'accélère rien. Il n'initialise aucune valeur. Un indice de tableau reste entier, il n'est jamais converti en réel.
```
VAR
    Index : INT;
    Valeurs : ARRAY[0..9] OF REAL;
    Mesure : REAL;
END_VAR

IF (Index >= 0) AND (Index <= 9) THEN
    Mesure := Valeurs[Index];
END_IF;
```
