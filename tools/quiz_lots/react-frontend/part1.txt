@003
Q: Quelle est la différence entre props et state ?
C: Les props viennent du parent, le state est interne

E: Un composant ne modifie pas ses props : elles appartiennent au parent. Son state lui appartient, et le modifier provoque un nouveau rendu. Quand deux composants doivent partager une donnée, on remonte le state dans leur parent commun.

@004
Q: Que renvoie useState(0) ?

@005
Q: Que fait ce composant au clic sur le bouton ?
C: Il affiche le compteur augmenté de 1
W: Il ne se passe rien, le state est figé
W: Il augmente le compteur de 2 à chaque clic
W: Il recharge entièrement la page du navigateur
E: setCompteur demande un rendu avec la nouvelle valeur ; React met à jour seulement le texte du bouton dans le DOM. onClick reçoit une fonction, pas un appel : onClick={augmenter()} l'exécuterait à chaque rendu.
```jsx
function Compteur() {
  const [compteur, setCompteur] = useState(0);
  return <button onClick={() => setCompteur(compteur + 1)}>{compteur}</button>;
}
```

@012
Q: Pourquoi cet effet doit-il renvoyer une fonction ?
C: Pour arrêter la minuterie au démontage
W: Pour renvoyer la valeur du compteur au parent
W: Parce qu'un effet doit toujours renvoyer quelque chose
W: Pour relancer la minuterie deux fois plus vite
E: La fonction renvoyée est le nettoyage : React l'appelle au démontage et avant de relancer l'effet. Sans elle, la minuterie continue après la disparition du composant et provoque une fuite.
```jsx
useEffect(() => {
  const minuterie = setInterval(rafraichir, 60000);
  return () => clearInterval(minuterie);
}, []);
```

@021

@042
Q: Que renvoie ce hook personnalisé ?
C: La valeur, après 300 ms sans frappe
W: La valeur saisie, immédiatement
W: Une promesse résolue après 300 ms
W: Le nombre de frappes de l'utilisateur
E: Chaque nouvelle valeur annule la minuterie précédente : la valeur retardée ne change qu'après une pause. On évite ainsi une requête à chaque lettre tapée dans un champ de recherche.
```jsx
function useRetard(valeur, delai = 300) {
  const [retardee, setRetardee] = useState(valeur);
  useEffect(() => {
    const minuterie = setTimeout(() => setRetardee(valeur), delai);
    return () => clearTimeout(minuterie);
  }, [valeur, delai]);
  return retardee;
}
```
