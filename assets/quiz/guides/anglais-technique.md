# Anglais technique (atelier et informatique)

## L'essentiel
- En maintenance comme en informatique, l'anglais sert surtout à lire : notices constructeur, messages d'erreur, documentation, tickets. Le vocabulaire précis compte plus que la grammaire.
- La révision espacée fait revenir un mot raté le lendemain, puis de plus en plus tard une fois su : quelques minutes par jour suffisent.
- Chaque mot se travaille dans les deux sens : reconnaître le terme anglais (QCM), puis le retrouver dans une phrase d'atelier (phrase à compléter).

## Les tournures de l'atelier
- Les consignes sont à l'impératif, sans sujet : « Close the valve », « Check the oil level », « Never run the machine with the guard removed ».
- Une panne se décrit par ce qui ne se fait pas : « The cylinder does not extend fully », « The sensor does not detect the part ».
- « Before you… » et « until… » donnent l'ordre des opérations : « Apply the lockout procedure before any work ».
- Les noms s'empilent, le dernier est le principal : « pressure gauge » est une jauge (de pression), « terminal block » un bloc (de bornes).

## Les faux amis à connaître
- actually : en fait (et non actuellement, qui se dit currently).
- eventually : finalement (et non éventuellement, qui se dit possibly).
- control : commande, régulation (le contrôle se dit inspection ou check).
- library : bibliothèque (une librairie est un bookshop).
- achieve : atteindre, réaliser (achever se dit complete ou finish).
- sensible : raisonnable (sensible se dit sensitive).
- assist : aider (assister à se dit attend).

## Le vocabulaire par famille
- Mécanique : bearing (roulement), shaft (arbre), gearbox (réducteur), belt (courroie), coupling (accouplement), seal (joint d'étanchéité), wear (usure), grease (graisse).
- Électricité : circuit breaker (disjoncteur), fuse (fusible), contactor (contacteur), wiring (câblage), terminal block (bornier), ground (terre), overload (surcharge), short circuit (court-circuit).
- Hydraulique et pneumatique : pump (pompe), valve (vanne), cylinder (vérin), hose (flexible), leak (fuite), pressure gauge (manomètre), solenoid valve (électrovanne), flow rate (débit).
- Sécurité : lockout (consignation), PPE (équipements de protection individuelle), hazard (danger), emergency stop (arrêt d'urgence), guard (protecteur), permit to work (permis de travail), near miss (presque-accident), risk assessment (évaluation des risques).
- Maintenance : breakdown (panne), troubleshooting (dépannage), spare part (pièce de rechange), work order (ordre de travail), downtime (temps d'arrêt), root cause (cause racine), shutdown (arrêt programmé), CMMS (GMAO).
- Automatisme : sensor (capteur), actuator (actionneur), PLC (automate programmable), drive (variateur), limit switch (fin de course), setpoint (consigne), HMI (interface homme-machine), encoder (codeur).
- Développement : release (version livrée), deployment (déploiement), rollback (retour arrière), branch (branche), merge (fusion), feature (fonctionnalité), code review (revue de code), debugging (débogage).
- Exploitation et projet : backup (sauvegarde), outage (panne de service), workaround (contournement), log file (fichier journal), requirement (exigence), deadline (échéance), issue (anomalie), stakeholder (partie prenante).

## En entretien
- Une offre qui demande « anglais technique » attend surtout que vous lisiez une notice ou un message d'erreur sans aide : citez un exemple concret (documentation constructeur, forum, ticket).
- Si l'oral est demandé, préparez trente secondes en anglais sur votre poste actuel : ce que vous maintenez, une panne résolue, un outil utilisé.
