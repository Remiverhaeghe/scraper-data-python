# Sigles de l'informatique et des réseaux

## L'essentiel
- Les sigles reviennent sans cesse dans les offres et les entretiens : mieux vaut savoir les expliquer en une phrase.
- Méthode : retenir le sens et un exemple concret plutôt que le développé mot à mot.

## Réseau
- IP : adressage des machines ; TCP et UDP : transport ; DNS : noms vers adresses ; DHCP : attribution automatique d'adresses.
- LAN, WAN, VLAN : réseau local, étendu, virtuel ; VPN : tunnel chiffré.
- NAT : traduction d'adresses privées vers publiques ; MAC : adresse de la carte réseau.
- HTTP et HTTPS, SSH, FTP et SFTP, SMTP pour le courriel.

## Développement
- API : interface entre logiciels ; REST : style d'API sur HTTP ; JSON et XML : formats d'échange.
- IDE : environnement de développement ; SDK : kit de développement.
- ORM : correspondance objets et tables ; CRUD : créer, lire, modifier, supprimer.
- CI/CD : intégration et déploiement continus ; TDD : développement piloté par les tests.
- MVC : modèle, vue, contrôleur.

## Données et systèmes
- SQL : langage des bases relationnelles ; SGBD : système de gestion de base de données.
- ETL : extraire, transformer, charger ; BI : informatique décisionnelle.
- OS : système d'exploitation ; VM : machine virtuelle ; CPU, RAM, SSD.
- SaaS, PaaS, IaaS : niveaux de service du cloud.

## Sécurité
- MFA : authentification à plusieurs facteurs ; SSO : authentification unique.
- TLS : chiffrement des échanges ; PKI : infrastructure de certificats.
- RGPD : réglementation européenne des données personnelles.
- SOC, SIEM : surveillance et corrélation des événements de sécurité.

## Entreprise et industrie
- ERP : progiciel de gestion intégré ; MES : pilotage de la production ; GMAO : gestion de maintenance.
- SCADA : supervision ; API ou PLC : automate programmable ; IoT et IIoT : objets connectés.
- ITIL : bonnes pratiques de gestion des services informatiques.

## Pièges fréquents
- Confondre API (interface logicielle) et API (automate programmable industriel).
- Réciter un développé sans savoir à quoi il sert.

## En entretien
- Si un sigle vous est inconnu, dites-le et proposez ce que vous en déduisez.
- Reliez chaque sigle à un outil que vous avez utilisé.
